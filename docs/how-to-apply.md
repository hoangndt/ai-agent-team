# How to Apply AI Agent Team to a New Project

## Step 1: Copy engine

Copy:

- engine/ai_run.py

To target project:

- .ai/bin/ai_run.py

## Step 2: Choose a template

Start from one of:

- examples/pclab/.ai/
- examples/generic_backend/.ai/

## Step 3: Update project_config.json

Set:

- project_name
- default_domain
- domain paths
- skills by role

## Step 4: Update CLAUDE.md

Define:

- repository structure
- primary focus area
- project constraints
- backend/frontend boundary

## Step 5: Update skills

Replace or edit:

- backend skills
- reviewer skill
- qa skill

## Step 6: Test with one small ticket

Run:

- init
- architect-prepare
- architect-complete
- dev-prepare
- dev-complete
- review-prepare
- review-complete
- qa-prepare
- qa-complete

## Step 7: Iterate

Tighten:

- skills
- CLAUDE.md
- project_config.json
